## 一、项目定位

**ColorYourModel** 是一个 Tauri 2 桌面应用：导入 3D 打印白模 STL，自动/半自动把网格切成语义区域（分区），交互式上色，一键导出带颜色的 3MF（及 OBJ），直接投入 OrcaSlicer / BambuStudio / Snapmaker Orca 切片打印。

```
STL 白模导入 ──► 网格基础设施（邻接图/KD树/法线）
      │
      ├─► 自动分区（8 种算法 + 统一后处理）
      ├─► 证据检测（平面/多视角/截面/眼睛）──► 四通道边级投票融合
      ├─► 种子生长（推荐种子 + 测地 Voronoi）
      ├─► 手动精修（套索/分区画笔/合并/拆分/重分割）
      │
      ▼
交互式上色（笔刷/喷漆/智能笔/填充/橡皮，后端为真理源）
      │
      ▼
导出 3MF（Bambu 兼容 paint_color 通道 + 机器/工艺/耗材预设）或 OBJ+MTL
```

## 三、数据流

1. **导入**：`load_model` → `stl_io` 解析 → f32 位模式 HashMap 顶点去重 → 法线/包围盒/默认灰色 `#8A8A8A8A`（`DEFAULT_FACE_COLOR=[138,138,138,255]`, model.rs:65）→ 双 KD-Tree → petgraph 面邻接图 → `MeshDataDto`（展平数组）回传。
2. **分区**：`auto_segment_v2(algorithm)` → `run_segmentation` 分发 → 算法本体 → `postprocess::refine_regions` → `rebuild_segments`。计算期间 mesh 被 `take` 出 Mutex 防主线程卡死（segment.rs:425-427），返回时 `face_colors: Vec::new()` 避免回传数 MB 未变 JSON（:450）。
3. **上色**：前端 raycast 命中面 → `invoke(paint 命令)` → 后端 KD-Tree 命中 + `mix_color` → `PaintResult{updatedFaces, updatedColors}` → 前端 `updateFaceColors` 增量写 GPU（`addUpdateRange` 只上传触碰区间）。
4. **导出**：`export_3mf_command(path, selection)` → 颜色 median-cut 量化 ≤16 槽 → `paint_color` 位打包 → quick-xml + zip → 写后校验非空。

## 四、网格基础设施（`src-tauri/src/mesh/`）

### 4.1 MeshModel（model.rs:68-131）

- 几何：`vertices/faces/normals`
- 颜色：`face_colors: Vec<[u8;4]>`（逐面 RGBA，3MF 导出直接读它）
- 分区：`segment_labels: Vec<u32>`、`segments: HashMap<u32,Segment>`、`next_manual_label`（手工标签高水位，**永不回收**，防撤销后标签复用错乱）
- 空间索引：`face_kdtree` + `vertex_kdtree`（kiddo）
- 邻接图：`face_adjacency: UnGraph<u32,()>`（petgraph 无权无向图）
- 邻接构建（`build_adjacency`, model.rs:285-340）：边→共享面 HashMap（min/max 归一化键）；**非流形边（>2 面共享）两两配对连边**——这是测地/洪泛正确性的显式修复。
- KD-Tree 防崩溃：`kd_point`（model.rs:234-243）按索引哈希加 ~1e-4 确定性扰动，规避 kiddo 在"同轴重合点超 bucket"时的 panic（UV 球导入闪退修复，lib.rs:69-126 回归测试）。

### 4.2 标签空间设计

- 自动分区标签：`0..N`
- 手工分区标签：`>= MANUAL_SEGMENT_OFFSET = 100_000`（model.rs:28）
- `preserve_manual=true`（默认）时自动算法先保存 ≥10 万的标签、跑完恢复（mod.rs:147-183）——自动重跑永不覆盖手工区。

### 4.3 撤销/重做（history.rs）

- **自反演条目**：只存"操作前、被触及面"的 `(face, color)` / `(face, label)` 对，同一条目 swap 后即可描述 redo；1.5M 面全模型操作约 12MB。
- **stroke 合并**：无 begin/end 协议，靠调用方传单调 `stroke_id`；相同 id + 相同 OpKind 且栈顶匹配才合并；`open_faces` 首见去重（一笔内重复涂同一面保留拖拽前颜色）。
- 5 种 `OpKind`：Paint / SegmentPaint / ManualRegion / Merge / Split。
- 上限：深度 50、字节预算 256MB，逐出最旧但**永不清空到 0**。
- IPC 返回双形态：增量补丁 or 全量（`labels_changed || faces>50_000` 时全量 + `rebuild_segments`；阈值 `MAX_INCREMENTAL_FACES` 定义于 commands/history.rs:26）。

## 五、智能分区算法族（`src-tauri/src/segment/`，23 模块）

### 5.1 统一入口（mod.rs）

```rust
run_segmentation(mesh, algo: &SegmentationAlgorithm, preserve_manual, on_progress) -> Vec<Segment>
```

`SegmentationAlgorithm` 是 serde 内标签枚举（`#[serde(tag="type")]`，camelCase），**8 个变体**即 8 种算法：

| 变体 | 专属参数 | 0 值语义（自动估计） |
|---|---|---|
| `Dihedral` | angle_threshold | —（前端默认 30°） |
| `ShapeDiameter` | k | 24 桶直方图峰数+1，夹 [2,12] |
| `CurvatureKMeans` | k, smoothing_iters, use_sdf, crease_threshold_deg | k=6；crease=20° |
| `SdfGraphCut` | k | 同 SDF 估计 |
| `Concavity` | k | 凹缝数×1.5，夹 [1,48] |
| `ConvexDecomposition` | max_hulls, concavity | hulls=32（夹 [2,64]）；concavity 无 0 值语义，恒 clamp [0.005, 0.2]，测试基准 0.05 |
| `CurveSkeleton` | max_hulls, concavity | 同上 |
| `FhGraph` | scale, curvature, concavity(权重) | scale 基准 0.3 |

### 5.2 共享后处理（postprocess.rs，595 行）

所有算法的统一收尾：`refine_regions = 连通域拆分 → 小区吸收 → (可选)弱边界溶解`。

**Hoffman & Richards 极小值规则**（transversality principle）贯穿全后处理：凹折痕计全角度、凸折痕 ×0.5（`CONVEX_CREASE_WEIGHT=0.5`）——视觉感知中凹缝比凸棱更强地提示部件边界。

| 常量 | 值 | 含义 |
|---|---|---|
| `min_region_faces(n)` | min(30, max(10, ceil(n×0.002)), max(1,n/20)) | 自适应小区阈值 |
| MAX_AUTO_REGIONS | 4096 | 超出则加倍门槛 |
| MAX_MERGE_PASSES | 40 | 吸收轮上限 |
| FEATURE_GAP_KEEP | 0.30 | 特征质心距超过则保留边界 |
| COPLANAR_EPS_DEG | 1.0 | 共面判定 |
| DEFAULT_CREASE_DEG | 20.0 | 默认折痕阈值 |

### 5.3 八种分割算法

#### ① Dihedral（dihedral.rs，486 行）— 二面角分裂

相邻三角形法线夹角 < 阈值则 Union-Find 合并 → 区域邻接图 → 平均法线点积 ≥0.93（≈21.8°）的区域合并（小并大）→ 碎片清理。最快，几何骨干通道。

#### ② ShapeDiameter / SDF（sdf.rs，715 行）— 形状直径函数

Shapira et al. 2008 的实用化：每面沿法线反向在 **60° 锥内投 12 条光线**（Möller–Trumbore 求交，候选面 = KD-Tree 最近 512 个面中心），取**命中距离中位数**为"厚度"；孔洞（未命中）≤5 轮邻域填补 → log 归一化 → 确定性 1-D k-means（排序种子 Lloyd，20 轮）→ 凹痕感知合并（最弱折痕边界优先合并，受 20° 门控）。

厚度场语义：粗的部分（躯干）与细的部分（四肢/耳朵）自然分离。

#### ③ CurvatureKMeans（curvature.rs，206 行）— 内蕴特征聚类

每面 2-D 特征 =（曲率，可选 SDF 厚度），**刻意排除法线方向分量**（对姿态/镜像不变）；法线先做 N 轮 Laplacian 平滑压噪声；**最远点采样（FPS）选种子的确定性 k-means**（首种子 = 最大范数点）。

#### ④ SdfGraphCut（graphcut.rs，545 行）— 能量优化分割

SDF 场上 GMM 软聚类（EM，50 轮）得后验 → MAP 硬标签作初值 → **Boykov alpha-expansion**（每轮内部 Dinic 最大流；节点 = 面 + 每边辅助节点 + S/T；t-link 代价 = −log 后验；Potts 平滑项 = −ln(θ/π)，凹边 ×1.0 / 凸边 ×0.1）求 MAP 标签，3 轮扩张。理论最正统的能量分割（BVZ 2001 风格）。

#### ⑤ Concavity（concavity.rs，664 行）— 凹度场（Au et al. TVCG 2012 简化版）

解**凹度感知 Laplacian** PDE：顶点高斯曲率（角亏）→ 相邻折痕多数投票判凹/凸 → 边权 `w=exp(β(|K_i|+|K_j|)+ε)`（凹边 β=0.01、凸边 1.0，即凹处导热差）→ 两个 Dirichlet 锚点（|K| 最大顶点）→ **共轭梯度求解**（300 轮 / 1e-5 容差）→ 场值 k-means。场在凹缝处产生阶梯，阶梯即分区边界。

#### ⑥⑦ ConvexDecomposition / CurveSkeleton（convex_decomp.rs，384 行）

parry3d **V-HACD** 分解为凸包（max_hulls 夹 [2,64]，resolution 128）→ 每面归最近凸包中心。CurveSkeleton 变体追加**肢体分组**：凸包邻接图中度 ≥3 的节点为分支点，删去后每个连通片 = 一个肢体（适合人形/动物）。

#### ⑧ FhGraph（fh.rs，382 行）— Felzenszwalb–Huttenlocher 自适应图分割

经典 FH 算法：边权 = curvature×折痕法向差 + concavity×显著度差；边升序贪心合并，判定式 `w ≤ min(Int(Cu)+scale/|Cu|, Int(Cv)+scale/|Cv|)`。**自适应阈值随区域增大而收紧**，天然产出多尺度分区。

### 5.5 眼睛语义识别（特色功能）

**两级流水线**：

1. **template.rs 全局找眼**（`detect_eye_regions_auto`）：`face_frame.rs` PCA 姿态归一化（幂迭代主轴 + 包围盒定向 + 右手性校正）→ 全网格逐面"球状度"（`ball_ratio`：邻域内球面内点 / (球内点+平面内点)，代数最小二乘球拟合 vs PCA 平面拟合）→ 候选掩码 = 球状度 ≥0.55 ∧ 最大折痕 ≤35° ∧ **头部眼带先验**（高度比例 [0.05,0.45]、|x| 比例 [0.05,0.60]、前 1/4 深度）→ 连通域过滤 [40,20000] 面 → **镜像配对**（尺寸比容差 2.0、空间容差 0.15）→ 无对取前 2。
2. **eye.rs ROI 细分类**：四类语义 Socket（眼窝）/ Eyelid（眼睑）/ Globe（眼球）/ Sclera（巩膜）。判别次序：球面+光滑 → 按到 ROI 中心距离环带切分（≥0.85×r 为 Sclera）；否则凹 → Socket；否则 Eyelid。**闭眼回退**：globe+sclera 面数 < max(roi/20, 8) 则丢弃（闭着的眼睛不该有眼球）。每区域带置信度。

输出 `EyeRegion{semantic, face_indices, boundary_edges, center, confidence}`，可直接作为融合通道的 `eye_sets`。

### 5.6 四通道融合（fuse.rs，669 行）— 边级多数投票

对**每条面邻接边**独立投票：

```
planar/multiview 通道：两侧标签不同 → cut +1；相同 → keep −1
dihedral 通道：       标签不同 → cut +1000（几何骨干，高权重）；眼睛面豁免
eye 通道：            恰一侧为眼睛面 → cut +1000（语义边界，最高优先级之一）
判定：cut − keep > cut_threshold（前端默认 2 = 真多数）则切开该边
```

被切边移除后取连通域 → 碎片（< max(8, n×0.002)）循环并入"巨区"（≤200 轮；**含眼区域锁定不被吞并**）→ 每区分配新手工标签 + 上色 + 一次 undo。`FuseResult` 携带各通道票数明细，经 `fuse-debug` 事件发给前端诊断。

设计要点：**单一算法都会错，但错得不一样**——投票让一致性结构（多通道都认为是边界的）胜出，单通道噪声被淹没。

### 5.7 种子生长流水线（recommend.rs + seeded.rs）

1. **推荐**（recommend.rs）：`face_significance = curvature 与 concavity 加权归一`；首种子 = 显著度**最小**面（最"平"处，通常在大部件中心），其后测地 FPS 最大化 `min_dist × (1−sig)`——既远离已选种子又偏好低显著度。
2. **生长**（seeded.rs）：种子吸附顶点（复用 manual.rs 三层吸附 + 数据退化全局兜底）→ 边权 = 质心距离，二面角 ∈ (barrier_deg, 180°−barrier_deg) 的边标记为**壁垒**（默认 45°）→ 含种子连通片内多源 Dijkstra **测地 Voronoi** → 无种子片带惩罚跨越兜底（惩罚 = 包围盒三轴 extents 之和 ×5，seeded.rs:243）→ 可选 optimizer 吸收小区（≤3 轮）。

### 5.8 交互编辑（manual.rs / split.rs / resegment.rs）

- **套索**（manual.rs，925 行）：点击吸附四层级（manual.rs:146-166）——Tier1 命中面一环同侧顶点（局部阈值 1.5×最长边内）→ Tier2 命中面同侧顶点 → Tier3 命中面任意顶点 → 全局最近兜底（注释明示 "Absolute last resort, only when face data is bad"，正常路径不可达）；同侧阈值 60°（覆盖 cube 角点 54.74°）→ 前壳面过滤（剔除背面）→ 顶点图 Dijkstra 加密循环 → 循环边为壁垒 BFS 取较小连通片 → 平衡形态学平滑边界（腐蚀"出>2×入"去毛刺 / 膨胀"入>2×出"补凹口）。
- **拆分**（split.rs）：Crease 法（折痕阈值连通域拆分）；Plane 法预留未实现。拆分产生的片提升为手工标签。
- **重分割**（resegment.rs）：单区提取子网格 → 对子网格重跑任意 `run_segmentation` → 结果映射回原面（新手工标签）。
- **通用洪泛**（flood_fill.rs，51 行）：面邻接图 BFS、受 segment 标签约束，被填充工具复用。
- **质量度量**（metrics.rs，422 行）：rand_index / boundary_f_score / hamming_distance / 连通性检查 + 黄金夹具（uv_sphere/unit_cube）。**当前为未接线资产**——评估函数在全仓库无非测试调用方，仅测试工具被各模块测试引用；接线上 UI 是现成 backlog。

## 七、3MF / OBJ 导出（`src-tauri/src/export/`）

### 7.1 关键工程决策：Bambu 兼容通道

标准 3MF 的 `basematerials`/`displaycolor`/`pid`/`p1` 通道**被明确禁用**（BambuStudio/OrcaSlicer 不读，测试 `no_basematerials_or_pid_are_emitted` 强制）。替代方案：

- `<triangle paint_color="...">`（**Bambu 私有扩展**，命名空间 `http://schemas.bambulab.com/package/2021`）：值是 **1-based 挤出机槽位号的位打包编码**（模仿 libslic3r `TriangleSelector::serialize()`：2 bit split_sides + state，nibble 逆序，大写十六进制；≤16 槽）
- 真实 RGB 颜色写在 `Metadata/project_settings.config` 的 `filament_colour` 数组（`#RRGGBB` 大写），槽位号与之对应
- 三角形按面序输出（mmu_segmentation 数组的顺序契约）

### 7.2 颜色量化（quantize.rs）

确定性 median-cut（BTreeMap 直方图 + 显式 tie-break），≤16 槽，主导色排 slot 1，alpha 丢弃。

### 7.3 机器/工艺/耗材预设（presets.rs + project_config.rs）

- `resources/presets/snapmaker_u1.json` 由 `tools/extract_orca_presets.py` 从 OrcaSlicer vendor 树萃取（vendor 白名单 + inherits 链解析），`include_str!` 编译期嵌入：Snapmaker U1，4 喷嘴变体（0.2/0.4/0.6/0.8）、30 工艺、113 耗材。
- selected 导出嵌入完整 `machine_settings_1.config`（含 gcode 宏）——切片器下拉框直接显示 "Snapmaker U1 (0.4 nozzle)"，**无需用户预装 vendor profile**。
- 悬空名字当错误而非静默降级；`printer_settings_id` 等必须逐字符匹配否则预设被 slicer 丢弃。
- generic 回退：Generic Printer / 0.20mm Standard / Generic PLA。

### 7.4 OBJ 导出（obj.rs）

per-face 颜色经 `usemtl` 分组 + 伴生 `.mtl`（Kd）；≤256 色精确保留，超出量化折叠。

## 八、前端架构（`src/`）

### 8.1 渲染管线（Viewport.tsx，2770 行）

- **正交相机**（Canvas orthographic），Z-up→Y-up 旋转挂载；CameraFit 按 bbox 定位（依赖数组刻意只依赖 `bbox`，防 undo/分区刷新导致相机回位）。
- 材质二选一：flat=`meshBasicMaterial`（逐面精确色，无光照）/ shaded=`meshLambertMaterial`。
- **BVH 拾取**：three-mesh-bvh 原型 patch（`acceleratedRaycast`）；关键参数 `indirect: true` 保持几何非索引、faceIndex == 后端面索引（否则重现 iteration-14 "画 A 色 B" bug）；`setTimeout(0)` 延迟建树不阻塞首帧；`firstHitOnly`。**GPU 像素回读方案已废弃**（README 中描述过时）。
- **GPU shader 分区高亮**（Option B）：`onBeforeCompile` 注入 per-vertex `aSegLabel`（flat varying）+ `uHighlightLabel/uHighlightColor` uniform，hover 切换 O(1)（替代重建几何的旧方案，是 giant 段卡死的根因修复）。
- 双颜色缓冲：paintColorArray（真实色）/ segmentColorArray（分区调色板视图）。
- `IdleFrameloop`：静止 1.5s 切 demand 渲染。

### 8.2 状态管理（appStore.ts）

zustand 单 store + persist（key `cym-prefs`），**partialize 白名单 11 键**：theme/language/shadingMode/brush 三参/currentColor/snapEnabled/lastExportSelection/lastAlgorithmParams/lastSegmentKind。`mergePrefs` 白名单 + 范围校验（brushRadius clamp 0.5-200 等）；算法参数走 `sanitizeAlgorithmParams` 值域校验。

### 8.3 交互要点

- **串行涂色队列** `enqueuePaint`：latest-wins 节流 + 异步串行 drain，修复乱序 IPC 导致的"颜色不跟光标"。
- 鼠标映射单写者 `applyCameraButtons`：View=LEFT 旋转；绘制工具 LEFT 在模型上=禁用 / 空白=旋转；**RIGHT=pan 常驻**；Alt 强制旋转。（README 所述 "Space 平移" 已不存在，仅存注释。）
- Ctrl+滚轮调笔刷半径（clamp 0.5-200，fill 工具故意排除）。
- 画笔光标：ringGeometry 环 + `useFrame` 直接读 ref 贴合法线（无 React 状态 churn）。
- 诊断体系（Tauri release 无 F12 的替代）：DebugHud hover/click 探针、lastPaintDebug 路由分解、PanDiag、DebugLogViewer。

### 8.4 SeedPanel 双模式

- **Auto(fuse)**：唯一参数 dihedralDeg（5-35°，默认 15）→ `fuse_segmentation(cutThreshold=2, minRegionFaces=0, dihedralDeg, eyeSets)`。
- **Manual(grow)**：推荐种子（count/curvWeight/concWeight 滑杆）→ 证据层检测（平面/多视角/截面）→ 生长（barrierDeg 10-90° 默认 45 + optimizer）。
- 两模式共享眼睛区域预留（自动眼检会先清空建议池防"碎成彩虹"；仅有眼种子无身体种子时拒绝生长）。

## 十、设计决策与文档漂移勘误

| 决策 | 理由 |
|---|---|
| 后端为真理源 | 颜色/标签/undo 单点持有，前端崩溃/刷新不丢编辑语义 |
| 手工标签 10 万偏移 + 高水位永不回收 | 自动重跑可安全 preserve_manual；撤销不会引起标签复用错乱 |
| 非流形边两两连边 | 测地/洪泛在坏网格上的正确性 |
| KD-Tree 1e-4 扰动 | kiddo 同轴重合点 panic（UV 球闪退） |
| BVH `indirect:true` | faceIndex 与后端面号对齐（iteration-14 根因） |
| shader 高亮替代重建几何 | giant 段 O(F)→O(1) |
| Bambu 私有通道替代标准 basematerials | 目标切片器实际读取行为（逆向验证） |
| 填充目标 = 点击面自身分区 | 修复"填 C 同色时 A 变色"（颜色不参与区域判定） |

**README 勘误**（README.md 与代码不符，以本文档为准）：
1. "GPU 面拾取（颜色编码 → RenderTarget → 像素读取）"（README.md:194-196）→ 实际为 three-mesh-bvh CPU raycast（GPU 回读方案已废弃）。注：README.md:40 已自述改用 BVH 并"明令禁止 GPU 回读"，与 :194 自相矛盾——README 内部新旧描述并存。
2. "Space 平移"（README.md:43）→ 不存在；实际 RIGHT=pan 常驻。
3. 架构示意中的模块清单（README.md:90,134-135，segment/ 仅列 dihedral+flood_fill 等）→ 实际 23 模块；README 也未列出完整 IPC 命令清单（实际 38 个）。
