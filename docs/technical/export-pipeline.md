# Export Pipeline (3MF / OBJ / Presets)

> Status: **placeholder** — content pending. Fill freely in English or 中文.

## Scope

From painted labels to slicer-ready files:

- **3MF**: object/model XML + Materials & Colors extension, ZIP packaging; embedded `machine_settings_1.config` so slicers show *Snapmaker U1 (0.4 nozzle)* without vendor profiles installed
- **Presets**: `resources/presets/snapmaker_u1.json` (generated by `tools/extract_orca_presets.py` from the OrcaSlicer vendor tree, whitelisted vendors + `inherits` chain flattening) compiled in via `include_str!`
- **Export dialog**: machine → nozzle → process → filament slots → target slicer; multi-region selection + apply-all; last-selection persistence with value sanitization
- **OBJ**: per-face colours as MTL material groups, quantized to ≤256 colours
- Verification record: see `../04` P0-4 (verified in Snapmaker Orca, 2026-08-27)
