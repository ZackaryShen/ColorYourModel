> 构建日期：2026-07-28 ｜ 平台：Windows (x64) ｜ Tauri 2 + React + Three.js

## 一、怎么拿到并运行

- **安装包（推荐）**：运行 `ColorYourModel_0.1.0_x64-setup.exe`，按向导安装，开始菜单/桌面生成快捷方式。
- **便携版**：直接双击 `color-your-model.exe` 即可运行（无需安装）。
- **运行前置**：Windows 10/11 自带 **WebView2** 运行时；若极少数精简系统缺失，首次启动会提示联网安装（标准行为，装一次即可）。

> 产物路径（已构建）：
> - 安装器：`src-tauri/target/release/bundle/nsis/ColorYourModel_0.1.0_x64-setup.exe`（3.1 MB）
> - 便携 exe：`src-tauri/target/release/color-your-model.exe`（13.8 MB）

## 二、这版能干嘛

### 1. 智能分区（SDF，Tier 0）
- 工具栏点「智能分区」→ 后端按 Shape Diameter Function 自动把模型切成语义部件并上色。
- 实测覆盖：两个分离部件（双立方体）、单部件、块体+薄板（凹接合）等。

### 2. 手动套索分区（带实时吸附 + 撤销）
- 工具栏切到「套索」模式。
- 鼠标在模型上移动时，**青色标记**实时显示"下一个点击将吸附到的顶点"（零延迟）。
- 点击选顶点，至少 3 个点；点回**起点**闭合区域，生成新的手分区并上色。
- 键位：
  - `Esc`：清空当前进行中的套索。
  - `Backspace`：删除上一个选点。
  - `Ctrl/Cmd+Z`：进行中有选点 → 删上一个点；无选点 → 撤销上一个已 finalized 手动分区。

### 3. 画笔分区
- 工具栏「画笔」模式可在面上直接涂色（当前不在此轮撤销范围内）。

## 三、已知限制（诚实告知，非 bug）

1. **自动估 k 可能过度分割**：单部件均匀网格会被拆成 2 段（`estimate_k` 下限为 2）。下一轮改用 gap 统计量估 k。
2. **凹接合处法线翻转**：薄板底面个别三角形可能被误读为"厚"，导致区域边界略有偏差。下一轮做朝向无关厚度（双向射线取 min）。
3. **吸附预览为前端本地计算**：与后端 kdtree 数学等价；百万级顶点 + 鼠标高速移动时预览重算可能偶发卡顿（点击吸附始终走后端 kdtree，不受影响）。
4. **未经真实 STL 端到端手测**：以上为 fixture 单测 + 链接验证，尚未用真实模型文件在 GUI 里跑通。
