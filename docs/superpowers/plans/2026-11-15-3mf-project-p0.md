# 3MF 工程文件 P0 实现计划（导入 / 工程 part / 历史持久化）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让本应用能读入任意 3MF（几何 + 原模型颜色 + 细分重建），并在自己导出的 3MF 里写入/读回工程状态（逐面分区标签、精确 RGBA、区域名、手工标签高水位、撤销历史），缺失或不匹配时回退到基础导入。

**Architecture:** 新增读取侧模块 `src-tauri/src/threemf/`（OPC 包、模型 XML、盘划分、调色板、paint_color 解码、三角形细分重建），新增 `src-tauri/src/export/project_state.rs`（工程 part 与交换容器的共用编解码 + 几何指纹），扩展现有 `export/threemf.rs` 写私有 part，`commands/mesh.rs` 的 `load_model` 增加 `3mf` 分派。几何由 3MF 的 mesh 承担，工程 part 只存 3MF 表达不了的逐面状态。

**Tech Stack:** Rust（zip 2、quick-xml 0.36、serde/serde_json、kiddo、petgraph）、Tauri 2、React 19 + TypeScript + Zustand、vitest。

**Spec:** `docs/superpowers/specs/2026-11-15-3mf-project-format-design.md`

**范围：** 本计划只覆盖 spec 的 P0（3MF 读入 + 工程 part 写出 + 历史持久化 + 回退）。P1（多盘 Tab、`model_settings` 写出、`tab_id` 命令层、联合调色板）与 P2（脏 Tab 换出）各自另立计划——P1 的写出策略要等三盘样本的真机结果才能定稿。

## Global Constraints

- 工程 part 主版本 `format_version = 1`；读到不认识的**主**版本 → 忽略工程 part，不拒开文件。
- 手工标签偏移 `MANUAL_SEGMENT_OFFSET = 100_000`（`mesh/model.rs`）；`next_manual_label` 读入后钳到 `max(存活手工标签)+1`。
- 挤出机槽位上限 `MAX_EXTRUDER_SLOT = 16`（`export/paint_color.rs`）；工程 part 保留量化前的精确 RGBA。
- 未涂装（无 `paint_color`）与叶子 `state = 0` 都解析为**槽 1 的颜色** `filament_colour[0]`；完全没有 `project_settings.config` 时用 `DEFAULT_FACE_COLOR = [138,138,138,255]`。
- 指纹 = FNV-1a 64，哈希域为**规范化坐标**：每个分量先 `format!("{:.6}", v)` 再 `parse::<f32>()`，取其 LE 字节，后接 `faces` 的 LE `u32`；外加顶点数/面数。
- 撤销历史持久化原始字节上限 64 MB，超出从**最旧** undo 条目开始丢。
- 单对象盘导入**不做顶点去重**（保持顶点顺序与数量，否则指纹必然失配）；多对象合并时才按位模式去重。
- 绝不因工程 part / `model_settings.config` 解析失败而拒绝打开几何合法的 3MF。
- 读取 ZIP 条目必须先按 file_size 预检再分配，损坏计数只能返回 `Err`，不得 panic 或超大分配。
- `model_settings.config` 的 `<part><metadata key="matrix">` 与 `source_offset_*` 不参与几何烘焙（与 component transform 数值近等，叠加即双重变换）。
- 测试命令：`cargo test --lib --locked --manifest-path src-tauri/Cargo.toml`、`npx tsc --noEmit`、`npx vitest run`。
- 真实样本不入库：`CYM_REAL_3MF`（`~/Downloads/梁圣.3mf`）、`CYM_REAL_3MF_MULTI`（`~/Downloads/model.3mf`），缺失时用例 skip。

## Review Focus

1. **被细分过的 paint_color**（`split_sides != 0`，真实文件里 8,945/13,364）：颜色必须完整还原、不 panic、不丢面 —— 只按叶子读取的实现会丢掉 67% 的上色三角形。

- [ ] **Step 3: 实现**

位流约定（源码依据：`TriangleSelector::serialize` / `deserialize` 与 `Model.cpp` 的 `CONST_FILAMENTS`）：字符串的 nibble 顺序是**反的**；每个 nibble 内 4 位按 LSB-first 组成一个 4 位 `code`。

```text
decode_node():
  code   = next_nibble()            // 读盘时：先反转 nibble 序列，再 LSB-first 取 4 位
  split  = code & 0b11
  if split == 0:                    // 叶子
      state = code >> 2
      if state == 0b11:             // 3 及以上的转义
          n = next_nibble()
          state = n + 3
          if n == 0b1111: state = next_nibble() + 18
      return leaf(state)
  // 细分节点：高 2 位是 special_side（3 边细分时恒为 0）
  special_side = if split == 3 { 0 } else { code >> 2 }
  serialized = (0..split + 1).map(decode_node).collect()   // 序列化顺序 = 槽位 K..0
  serialized.reverse()                                     // 还原成槽位顺序
```

`leaf_slots` 按槽位顺序深度优先收集叶子 `state`。`hex` 必须是偶数长度？不：C++ 逐 nibble 读，字符串按字符解析为 nibble；非十六进制字符返回 `Err`。

fn area(v: &[[f32; 3]], f: [u32; 3]) -> f32 {
    let a = v[f[0] as usize]; let b = v[f[1] as usize]; let c = v[f[2] as usize];
    let ab = [b[0]-a[0], b[1]-a[1], b[2]-a[2]];
    let ac = [c[0]-a[0], c[1]-a[1], c[2]-a[2]];
    let n = [ab[1]*ac[2]-ab[2]*ac[1], ab[2]*ac[0]-ab[0]*ac[2], ab[0]*ac[1]-ab[1]*ac[0]];
    (n[0]*n[0] + n[1]*n[1] + n[2]*n[2]).sqrt() * 0.5
}

- [ ] **Step 3: 实现**

按 `TriangleSelector::perform_split`（OrcaSlicer `src/libslic3r/TriangleSelector.cpp`）逐行移植；中点分配用自己的缓存替代 `triangle_midpoint_or_allocate` 的邻居查找：键 = 顶点索引对 `(min, max)`，值 = 新顶点索引，命中即复用（这是"共享边不裂缝"的唯一保证）。

```text
expand_node(base_v, out, tri_verts: [u32;3], node):
  if node.split == 0: out.faces.push(tri_verts); out.slots.push(node.state); return
  s = node.special_side                    // 3 边细分时恒 0
  v = [tri_verts[s], tri_verts[(s+1)%3], tri_verts[(s+2)%3]]
  match node.split:
    1 => m = mid(v[2], v[1]);  v.insert(2, m)
         emit children[0] on (v[0],v[1],v[2]); children[1] on (v[2],v[3],v[0])
    2 => m1 = mid(v[1], v[0]); v.insert(1, m1)
         m2 = mid(v[0], v[3]); v.insert(4, m2)
         children[0] (v[0],v[1],v[4]); children[1] (v[1],v[2],v[4]); children[2] (v[2],v[3],v[4])
    3 => m0 = mid(v[1], v[0]); v.insert(1, m0)
         m1 = mid(v[3], v[2]); v.insert(3, m1)
         m2 = mid(v[0], v[4]); v.insert(5, m2)
         children[0] (v[0],v[1],v[5]); children[1] (v[1],v[2],v[3]);
         children[2] (v[3],v[4],v[5]); children[3] (v[1],v[3],v[5])
```

`mid(a, b)` 用 `(min,max)` 查缓存；否则插入新顶点 `(v[a] + v[b]) * 0.5`（f32 逐分量）。递归深度上限 64，超出返回 `Err`（真实文件最大 9 层）。

- `transform` 解析：12 个 f32 空格分隔；`compose` 按 3MF 行向量矩阵乘法（`build` 在外层）。
- 外部 part：遇到 `p:path` 就解析该 part（`3D/_rels/<name>.rels` 不需要，`p:path` 已是包内路径；剥前导 `/`），解析结果缓存进 `parts`，防止重复解析（同一 part 只解析一次）。
- 未知/缺失属性一律容忍：`paint` 缺失 → `None`；`transform` 缺失 → identity。

- [ ] **Step 3: 实现**

```text
read_project(path, progress):
  pkg = Package::open(path)
  scene = model::read_scene(&mut pkg)        // 坐标已按 unit 换算为毫米（Task 3）
  settings = pkg.read("Metadata/model_settings.config") -> parse().unwrap_or(empty)
  groups = plates::group(&scene.build, &settings)
  for (i, group) in groups.enumerate():
      progress(...)
      assembled = assemble::assemble(&scene, group)
      trees = assembled.paint.map(|p| p.map(paint::decode)).collect()  // None 保持 None
      expanded = subdivide::expand(&assembled.vertices, &assembled.faces, &trees)
      palette = pkg.read("Metadata/project_settings.config").ok()
                     .and_then(|b| materials::palette_from_project_settings(str).ok())
      base_slot = settings.objects[object_id].extruder  // 该组唯一对象时
      colors = materials::resolve(&expanded.slots, palette.as_ref(), base_slot)
      mesh = MeshModel { vertices: expanded.vertices, faces: expanded.faces,
                         face_colors: colors, segment_labels: vec![0; faces.len()],
                         unit: "millimeter", ..new() }
      engineering = try_restore(&mut pkg, plate_index, &mut mesh)   // 下面
      rebuild_derived(&mut mesh)   // normals → bbox → rebuild_segments → kdtree → vertex kdtree → adjacency
      plate = ImportedPlate { plater_id, name, mesh, engineering }
```

`try_restore(pkg, plate_index, mesh) -> bool`：读 `Metadata/cym/project.json` → `decode_project_json`（失败 → `false` + `log::warn!`）；按 plate 序号定位条目（索引越界 → 用第 1 条）；**指纹用 `fingerprint_of(&mesh.vertices, &mesh.faces)` 现算**（此时几何已细分、已是毫米，与写出侧同域）；与 header 的三字段比对，全等才算命中；命中则 `decode_plate_state` 覆盖 `face_colors`/`segment_labels`/`segment_names`/`next_manual_label`，`decode_history` 覆盖 `mesh.history`（`Ok(None)` 表示历史不可读，保持空栈），并对 `next_manual_label` 做 `max(存活手工标签)+1` 钳制；任何一步失败都返回 `false`。

单位换算放在细分之后、颜色解析之前，保证指纹语义与写出侧一致（写出侧永远写毫米）。
