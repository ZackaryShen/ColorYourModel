## 0. 说明

### 0.1 优先级定义

| 级别 | 含义 |
| --- | --- |
| **P0** | 核心路径 / 数据安全 / 崩溃级缺陷。任一失败即阻塞发版。 |
| **P1** | 重要功能，应在发版前通过。 |
| **P2** | 边界、体验、次要场景；尽力覆盖，可接受记录遗留。 |

### 0.2 测试环境

- 桌面端：Tauri 2 + WebView2（Windows）/ WKWebView（macOS）/ WebKitGTK（Linux）。
- 前置数据：需自备 `samples/` 下任意 STL（如 `liangsheng` 手办、`Sphere.stl`、`house2`），以及一个已融合出 ≥2 个分区的模型用于分区类用例。
- 每个用例「预期结果」均为**手工验收判据**；「截图编号」留空由执行人填写。

### 0.3 术语对照

- `mergePicked`（代码内状态名，CHANGELOG 描述为「pickedRegions / 统一多选」）：查看工具 Ctrl+点击、填充工具 Ctrl+点击、分区面板行 Ctrl+点击共享的同一份选中集合，`[0]` 为「首个选中 / 保留者」。
- 「清空分区」= SeedPanel 的「清空全部」按钮；「重置分区」= SegmentsPanel 的「重置」按钮；两者都走后端 `reset_segmentation`，并由 `ResetConfirmDialog` 守卫。
- `DEFAULT_FACE_COLOR` = 未涂装默认灰 `[138,138,138,255]`（前后端互指，前端 `DEFAULT_FACE_COLOR_RGBA`）。
